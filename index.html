Häufige Fragen

Wo wird mein Spielstand gespeichert?

Nur auf deinem Gerät. Wenn du die App löschst, ist auch der Spielstand weg. In deinem Geräte-Backup kann er enthalten sein.

Wie teile ich ein eigenes Level?

Im Level-Editor das Level einmal selbst schaffen (Pflicht-Test), dann auf „Teilen“ tippen. Freunde scannen den QR-Code mit der iPhone-Kamera oder fügen den Code unter „Eigene Level → Code einfügen“ ein.

Braucht das Spiel Internet?

Nein. Trapforge läuft vollständig offline, ohne Konto und ohne Werbung.
